Park Master 3D is a 3D night-lot parking game: drive a car with arcade physics (throttle, steering, handbrake drift), and park it cleanly in the glowing bay across 10 levels of rising difficulty — tight spots, reverse-in bays, slalom cones, and a rush-hour lot. Stars are earned for speed and a clean car. Free roam included.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — or open `game/index.html` directly in a desktop browser. No network requests, keyboard only: WASD/arrows to drive, Space handbrake, C camera, R reset, P pause.
